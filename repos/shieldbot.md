# shieldbot

- Fork: [Blockchains/shieldbot](https://github.com/Blockchains/shieldbot)
- Original: [Ridwannurudeen/shieldbot](https://github.com/Ridwannurudeen/shieldbot)
- Description: Transaction security for EVM chains. ShieldBot checks tokens, approvals and signatures before a wallet signs, says what it checked, and reports Unknown instead of Safe when evidence is missing. Browser extension, Telegram bot, REST API, MCP server and SDKs. Covers Ethereum, BNB Chain, opBNB, Base, Arbitrum, Polygon, Optimism and Robinhood Chain.
