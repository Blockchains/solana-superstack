# PayAnywhere

- Fork: [Blockchains/PayAnywhere](https://github.com/Blockchains/PayAnywhere)
- Original: [0xAfterSnow/PayAnywhere](https://github.com/0xAfterSnow/PayAnywhere)
- Description: PayAnywhere is a cross-chain payment link generator built on Solana. Merchants create a shareable payment link in seconds buyers can pay from any supported EVM chain (Ethereum, Base, Arbitrum, and more) while the merchant always receives USDC on Solana. No chain-switching, no friction, no bridge knowledge required.
