- Description: TrancheLock is a Solana protocol for milestone-gated funding of autonomous coding agents. Sponsors lock capital in programmable vaults, while agents earn each tranche by delivering software that passes private sponsor-defined tests. Verified execution produces signed proof that authorizes onchain settlement.
