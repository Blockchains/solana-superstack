# qupon

- Fork: [Blockchains/qupon](https://github.com/Blockchains/qupon)
- Original: [savvax/qupon](https://github.com/savvax/qupon)
- Description: Corporate-actions engine for tokenized bonds on Solana. It finds the holders, calculates what each one is owed, pays them and records the result on-chain, following Kazakhstan market rules and emitting ISO 20022 messages. Covers coupons, redemptions, bondholder votes and DvP trades. Built with Anchor and Token-2022 on devnet for KASE × Superteam KZ
